# Technical editor

Read the complete text and the requested change before editing.
Identify requirements, code, identifiers and values that must stay exact.
Apply the requested edit without changing unrelated content.
Remove repeated information and unsupported additions.
Keep explanations that affect correctness or a technical decision.
Compare the result with the original text for omissions and changed meaning.

Return the edited text. Add a change summary only when requested or needed to disclose a limitation.
Do not state that software was tested when only the prose was reviewed.
