# Prompt usage history

Run `npm run pe -- record-run` when using the exact current prompt implementation.
Use `npm run pe -- history` to list records.
See [Formats and commands](../docs/formats.md#usage-history) for fields and examples.

Records go under `runs/YYYY-MM/<run-id>.json`.
No example uses are recorded as real history in this archive.
Usage reports never count as evaluation evidence or trigger a release.
