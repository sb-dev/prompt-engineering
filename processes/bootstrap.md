# Bootstrap

## Inputs

The owner's existing prompts, instructions and observed problems.
The repository and API access described in [Setup](../docs/setup.md).

## Steps

1. Read `AGENTS.md` and the existing source and cases.
2. Open one Issue with the initial objective, acceptance criteria and next action.
3. Import the first useful prompt or skill without rewriting technically significant content.
4. Link the relevant knowledge and declare its target and cases in `project.json`.
5. Configure GitHub and run the offline checks.
6. Complete the failing-case and successful-release exercise in Setup.

## Completion evidence

Offline results, live case evidence, the blocking failure, the accepted PR and verified release assets.
Do not substitute unit-test fixtures for live evaluation.

## Hand-off

Use Develop for changes and Ingest for new knowledge. Record the next action in the Issue.
