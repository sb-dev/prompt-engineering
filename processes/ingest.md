# Ingest

## Inputs

A repository and ref, research question, optional paths and exclusions.
For a usage observation: the actual prompt, output, application, model label and settings when available.

## Steps

1. Check whether existing knowledge already answers the question.
2. Run the Ingest GitHub workflow, or create an explicitly user-reported observation.
3. Check the pinned SHA, source links, quoted lines, licence and scope coverage.
4. Separate observed source patterns from interpretation and candidate applications.
5. Add useful findings to existing knowledge pages rather than duplicating them.
6. Review the generated Issue and PR. Broaden partial analysis when its omissions matter.

## Completion evidence

A research record or observation with provenance, limitations and useful linked findings.
For no-change analysis, the workflow record is sufficient.

## Hand-off

A candidate instruction change becomes a Develop Issue with an acceptance case.
Ingestion alone does not establish that a prompt or skill is better.
